# 经阴子宫双附件彩超检查什么

> 更新时间：2026-09-15 (UTC+8)

经阴子宫双附件彩超，也被称为阴超检查，是通过阴道进行的超声检查方法，能够更直接地观察子宫、卵巢及输卵管等附件区的结构和病变情况。

**1、子宫检查**

- 子宫形态与大小：评估子宫的形态是否规则，大小是否在正常范围内，以排除子宫畸形或异常增大的情况。
- 子宫内膜情况：观察子宫内膜的厚度、回声是否均匀，有无内膜息肉、内膜增生或内膜癌等病变。这对于诊断子宫内膜疾病具有重要意义。
- 子宫肌层：检查子宫肌层是否均匀，有无子宫肌瘤、子宫腺肌病、子宫腺肌瘤或子宫肉瘤等病变。

**2、卵巢检查**

- 卵巢形态与大小：评估卵巢的形态是否规则，大小是否正常，以排除卵巢增大或萎缩的情况。
- 卵巢病变：检查卵巢有无囊肿、肿瘤等病变，包括卵巢良性肿瘤、卵巢癌、多囊卵巢综合征、卵巢巧克力囊肿等。
- 卵泡发育：对于需要监测卵泡发育的女性，阴超可以清楚地看到卵泡的大小、形态及生长发育情况，有助于指导受孕。

**3、输卵管检查**

- 虽然阴超对输卵管的直接显示效果有限，但可以通过观察输卵管周围的结构和积液情况，间接评估输卵管是否通畅或存在积水等问题。

**4、盆腔检查**

- 盆腔积液：检查盆腔内有无积液，以及积液的量和性质，有助于诊断盆腔炎、盆腔积脓等病变。
- 盆腔肿块：对于盆腔内的肿块，阴超可以明确其位置、大小及囊实性，为进一步的诊断和治疗提供依据。

检查前需要排空膀胱，并尽量穿戴方便脱换的衣物和鞋子，以便于检查。检查后回家最好清洗外阴，以防交叉感染。对于无性生活史的女性或阴道有急性炎症、出血等情况时，应避免进行阴超检查。
