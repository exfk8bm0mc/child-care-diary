# 38岁在东阳人民医院做试管婴儿一次成功率有50%吗？

> 更新时间：2026-09-17 (UTC+8)

我今年38岁了，之前在北京做过一次试管成功了，这几年回了老家东阳，我儿子都已经20多了，现在我还想再生一个，所以就准备在当地的东阳人民医院做试管。之前有了解这个医院有技术，但我这个年龄在东阳人民医院做试管一次成功的概率高吗？试管一次的成功率能达到50%吗？

患者38岁在东阳人民医院试管一次的成功率大概有35%-40%左右，不到50%。因为38岁已经属于高龄范畴了，女性超过了35岁卵巢功能衰退就比较严重、卵泡减少、卵子质量变差，一次成功的几率就降低了。东阳人民医院目前开展的试管技术有一代、二代试管婴儿技术，该院做高龄试管一般都是采用的第二代试管技术，二代试管成功率在40%-50%左右，40岁以下的高龄试管的成功率在35%-40%左右。

东阳人民医院在2018年正式运行辅助生殖技术，并在同年取得了首例试管婴儿胚胎移植成功，目前东阳人民医院的试管成功率可以稳定在40%-50%左右，不过每位患者的情况不同，其试管成功率也有差异。一般年龄越大，试管成功率越小。下面是东阳人民医院年龄与试管试管成功率的关系分析：

- 1. 患者在25-30岁是最适合做试管的年龄，一般情况下，这个年龄段的患者卵巢功能比较好，卵子/精子质量优秀，培养出来的胚胎优质，试管成功率高，一次试管成功率大概在50%左右；
- 2. 30-35岁的患者，卵巢功能变差，卵子质量下降，试管一次成功率在45%左右；
- 3. 当患者超过了35岁，就已经步入了高龄，但如果没有超过43岁，这个年龄段的患者试管一次成功率在35%-40%左右；
- 4. 一旦患者迈过了43岁，一次试管的案例几乎没有，其一次成功率就在15%-20%左右。
东阳人民医院是东阳试管婴儿医院中比较出名的，试管成功率比较高，但针对于38岁的高龄女性，其试管一次成功率是不到50%的，这个年龄在东阳人民医院做试管的患者一次成功的还是有的，只不过很少。
